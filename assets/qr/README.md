# Rocket Game 42 QR code

`rocketgame42-module-qr.svg` / `.png` encode the babuni.dev deep link

    https://www.babuni.dev/#project=rocket-game-42&read=play-live

which opens the **Play Rocket Game 42** module on the website, with the Play button for `https://babuni.dev/Rocketgame42/`. Use either file to share or print. The website shows a WebP copy (`public/media/rocket-game-42/images/rocketgame42-qr.webp` in the babuni.dev repository).

Generated 2026-11-21 by Claude Code (Claude Opus 5.5) with the segno library (QR version 4, error correction M, 4-module border); the PNG was decoded back to the link above to check it.
