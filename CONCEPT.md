# Raketenspiel 42 — Creative Concept

## What the existing game communicates

**Project:** Raketenspiel 42 (also catalogued as Rocket Game 42). The game presents a compact arcade defence scenario: **defend the mothership** while incoming rockets, asteroids, and an enemy craft threaten it. The player steers a ship with the mouse and uses laser fire and earned seeker missiles. Score, level, life and laser energy establish ongoing survival/progression pressure.

These are **observations from the committed code and game UI**, not a newly invented or retrospectively approved design brief.

## Identifiable design characteristics

- A 550 × 400 playfield inherited from the Flash-era HTML and retained as the SVG viewBox in the remake.
- Mouse steering and hold-left-click laser fire; right-click launches seeker missiles.
- Colored special asteroids: blue restores protection/life, green replenishes laser energy, red is dangerous and should be destroyed.
- Score-based acquisition of seeker missile pods; a local high-score board records player name, points, and level.
- A modern playable presentation without a Flash plug-in, with an offline Electron Windows packaging route.

## Creative chronology

The repository includes older SWF and HTML files, including numbered variants ending in 42. A historical HTML launcher uses Flash-era APIs; a local file listing previously showed a 2009 timestamp, but **file timestamps alone cannot establish authorship dates or specific design decisions**. The source README describes the present JS/SVG project as recovered from a v1.42 Electron executable rather than from an original Flash .fla.
